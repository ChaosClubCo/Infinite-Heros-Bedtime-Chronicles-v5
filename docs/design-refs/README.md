# Design Reference Screenshots

UI design-exploration screenshots for Infinity Heroes: Bedtime Chronicles,
uploaded 2026-07-18 (originally at the repository root; relocated here to keep
the root clean). Each folder is one explored screen or variant, named after the
screen it mocks up, containing a single `screen.png`.

These are **static design references only** — nothing in the app, server, or
build pipeline reads from this directory. The same set was also uploaded to the
(now archived) public mirror `Krosebrook/Infinite-Heros-Bedtime-Chronicles-v5-main`.
