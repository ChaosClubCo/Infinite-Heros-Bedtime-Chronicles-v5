Privacy Policy

Infinity Heroes: Bedtime Chronicles — Last updated: July 18, 2026

Summary for Parents: Child profile name and age stay on the device and are discarded by the server before AI requests are built. A parent may create an optional account for cloud backup. Voice Chat is unavailable in this release: the app does not request microphone permission or send Voice Chat audio. Delete All Data removes the parent account, cloud records, any retained legacy Voice Chat history, and local device data after server deletion succeeds.

1. Information We Collect

Stored on the Device:

  • Child profiles, including name, age range, favorite hero, and avatar choices
  • Generated stories, illustrations, narration cache, badges, streaks, and achievements
  • App settings and parent controls, including the locally protected parent PIN
  • A parental-consent record containing the consent version, exact disclosure hash, acceptance time, locale, and parent-gate verification method

Optional Parent Account and Cloud Backup:

  • A parent email address, account identifier, and authentication records are handled by Supabase
  • When cloud backup is enabled, stories and progress records are stored under the parent account
  • The cloud profile stub does not contain the child's name or age

Sent to Our Services and Approved Providers:

  • Fictional hero details and parent-selected story preferences needed to create a story
  • Explicit child profile name and age fields are discarded by the server and are not included in story or suggestion provider prompts
  • Approved text for narration or other requested media generation
  • No Voice Chat audio is collected or sent by the current release

Retained on Our Servers:

  • Cloud-backup records when the parent turns that feature on
  • Any legacy Voice Chat conversation titles and sanitized transcripts created by a previously approved build, until their retention period expires or the parent uses Delete All Data
  • Security, rate-limit, request, and error information needed to operate and protect the service

The current release does not intentionally collect or retain raw Voice Chat recordings. AI providers may process or retain other requested generation data according to the provider terms and agreements applicable to the production service.

2. How We Use Information

  • Generate bedtime stories, illustrations, and narration
  • Save and synchronize stories and progress when a parent enables cloud backup
  • Authenticate the parent account and enforce owner-only access
  • Prevent abuse, investigate errors, and protect service reliability
  • Verify that parental consent matches the exact current disclosure version

We do not use child information for targeted advertising, sale of personal information, or behavioral profiling.

3. Service Providers

Depending on the feature and current production configuration, providers may include Supabase for authentication and cloud storage; OpenAI, Google Gemini, Anthropic Claude, or other approved AI providers for text and image generation; ElevenLabs for narration; and infrastructure or error-monitoring providers.

Voice Chat processing is not enabled for this release. Any future release that enables microphone or transcription processing requires separately recorded provider, privacy, retention, safety, device, and app-store approvals plus a new parental-consent version.

4. Children's Privacy and Parental Consent

  • A parent or guardian must pass the grown-up gate and consent before protected app features are available
  • The consent record stores the current version, exact disclosure hash, timestamp, locale, and parent-gate method
  • Material disclosure changes invalidate older records and require renewed consent
  • Accounts and cloud backup are optional parent-controlled features
  • There are no public child profiles, stranger messaging, advertising networks, or social feeds
  • Child-facing AI responses are generated under a child-safety policy and checked before display or narration
  • Voice Chat is unavailable in this release and cannot receive release credit from configuration alone

5. Data Retention

  • Device data: remains until the parent deletes it, resets the app, or uninstalls the app
  • Cloud backup: remains until deleted by the parent or the parent account is deleted
  • Legacy Voice Chat transcripts: are automatically purged no later than 30 days after creation and are also removed by Delete All Data
  • Parent authentication: remains until the parent account is deleted
  • Operational and provider records: follow documented production settings and applicable provider agreements

6. Parental Rights

Parents and guardians can:

  • Turn cloud backup off
  • Delete individual child profiles, stories, and progress records
  • Use Delete All Data to remove retained server data, the Supabase account and cloud records, and local device data
  • Receive a PII-free server deletion receipt that includes the deployed release identity
  • Withdraw consent and restart the parental-consent flow
  • Contact us to ask a privacy question or report a deletion problem

7. Data Security

We protect data in transit using HTTPS/TLS. Server endpoints use authentication, owner scoping, rate limiting, input validation, bounded context, and server-authoritative output safety checks. The current client contains no Voice Chat microphone, recording, transcript-fetch, or audio-message path.

8. Changes to This Policy

We may update this policy as the service changes. The Last updated date at the top identifies the current version. Material changes to child-data practices require an updated parent-facing notice and renewed consent.
